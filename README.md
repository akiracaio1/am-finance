# AM Finance - Sistema de Gestão Inteligente

Este é um sistema de gestão financeira profissional construído com Next.js 15, Firebase e Genkit (IA).

## 🚀 Como publicar o site (Deploy)

Para que o site fique acessível publicamente na web, siga estes passos:

1. **GitHub**: Crie um novo repositório no seu GitHub (ex: `am-finance`).
2. **Push**: Envie o código deste projeto para o repositório criado.
3. **Firebase Console**:
   - Vá em [App Hosting](https://console.firebase.google.com/project/_/apphosting).
   - Clique em "Começar".
   - Conecte seu repositório do GitHub.
   - Selecione a região `us-central1`.
   - O Firebase gerará automaticamente uma URL pública (ex: `https://seu-projeto.web.app`).

## 🛠 Tecnologias
- **Frontend**: Next.js 15 (App Router), Tailwind CSS, ShadCN UI.
- **Backend**: Firebase Auth & Firestore.
- **IA**: Genkit com Google Gemini para análise de dados.
- **Planilhas**: Integração avançada com Excel (xlsx).

## 📋 Funcionalidades
- Fluxo de Caixa Diário.
- Contas a Pagar/Receber com multi-filtros.
- Importação inteligente de planilhas.
- Conciliação Bancária.
- Relatórios estratégicos com Insights de IA.
