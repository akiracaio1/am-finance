# **App Name**: Yumi Yumi 🍣 Finance

## Core Features:

- Base Data Management: Register and manage suppliers (CNPJ, contact, category), chart of accounts (hierarchical categories), and bank accounts for reconciliation.
- Accounts Payable Management: Manually launch accounts payable entries with details like supplier, due date, amount, interest/fines, description, and account plan. Track status (open, paid, overdue) and mark entries as paid.
- Accounts Receivable / Billing Overview: Import revenue reports from Excel or CSV. View and filter revenue by period, category, and sales channel for basic analysis.
- Bank Reconciliation (OFX Import): Import OFX bank statements. The system automatically attempts to match transactions with existing accounts payable/receivable by value and date. Provides an interface to review and confirm matched/unmatched items.
- Intelligent Financial Analysis: An 'Analyze with AI' tool button that interprets the current financial data (like cash flow, DRE, outstanding accounts) to provide key insights and business recommendations.
- Cash Flow Planning & Control: A simplified interface to visualize and plan daily cash inflows and outflows, providing a clear overview of upcoming financial movements.
- Basic Financial Reporting: Generate essential financial reports, including a simplified Income Statement (DRE), Cash Flow Statement by period, and lists of overdue and upcoming accounts.

## Style Guidelines:

- Scheme: A clean and organized light theme, drawing inspiration from natural materials and clarity, reflecting both the sushi theme and financial precision.
- Primary color: A sophisticated, muted rose-brown (#7A5951) that conveys warmth and professionalism without being overly bold. HSL: (10, 20%, 40%).
- Background color: A very subtle, warm off-white (#F4F1F0), keeping the same hue as the primary but heavily desaturated for an open and clean feel. HSL: (10, 15%, 95%).
- Accent color: A soft, muted plum (#BA7593) to provide a gentle yet distinct contrast for calls to action or key highlights. HSL: (340, 30%, 60%).
- All text: 'PT Sans' (sans-serif) for its blend of modern readability and subtle personality, ideal for both headlines and data-heavy body text in a financial application.
- Icons: Utilize a set of clean, line-based icons with subtle curves, focusing on functionality and clarity for data visualization and navigation.
- Structure: A clear, multi-columnar layout optimized for presenting tabular data and financial summaries. Emphasize responsive design for various screen sizes, focusing on efficient data entry and overview.
- Interaction: Subtle and smooth transitions for data filtering, report generation, and status updates, providing gentle feedback to user actions.
